# Rentflow Backend

Complete backend server for Rentflow rental property management platform.

## Stack
- Express.js
- Supabase (PostgreSQL)
- Stripe (Payments)
- Twilio (SMS)
- Claude API (AI)

## Setup

1. Clone this repo
2. Copy `.env.example` to `.env`
3. Fill in all environment variables
4. `npm install`
5. `npm start`

## Deployment

Deployed to Railway.
